## 复现本轮检查

覆盖率命令已在 Node.js 24 环境验证，使用该版本运行：

```sh
npm run test:coverage
node scripts/check-release.js --code-only
npm run package:minigame
```

全套测试需要 Git、系统 `zip/unzip` 和部分集成测试使用的 POSIX `sh`，推荐当前Linux云环境、WSL或具备这些工具的macOS。正式身份配置完成后再运行 `npm run release:check`，平台验证仍按 [发布说明](RELEASE.md) 执行。

普通开发检查、覆盖率测量、发布身份预检和线上审核分别记录。覆盖率命令目前用于测量，没有设置最低覆盖率门槛；其退出成功不表示覆盖率已达到最终验收标准。
