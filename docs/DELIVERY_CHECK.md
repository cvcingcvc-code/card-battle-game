## 复现

在具备Git、zip/unzip及POSIX sh的Node.js24环境执行：

```sh
npm run test:coverage
node scripts/check-release.js --code-only
npm run package:minigame
```

覆盖率命令默认输出终端，未设置最低覆盖率门槛。需要LCOV文件时可添加双报告参数：

```sh
mkdir -p .artifacts/quality
npm run test:coverage -- --test-reporter=spec --test-reporter-destination=.artifacts/quality/gameplay-tests.txt --test-reporter=lcov --test-reporter-destination=.artifacts/quality/gameplay-coverage.lcov
```

真正平台验收见 [发布说明](RELEASE.md)，接入见 [中文指南](../微信小游戏接入指南.md)。
