# 余烬对决 1.1.0 · 微信小游戏发布候选

已经选定微信小游戏路线，当前单人三对三新增疾风/铁壁试炼、三选一祝福与星级目标。当前交付是可导入的小游戏源工程；真正编译、真机、上传和审核需要小游戏账号及微信开发者工具的实际结果。

## 最短操作路径

1. 下载 `.artifacts/minigame/ember-duel.zip`，解压后确认所选目录直接包含 `game.js`、`game.json`、`project.config.json`。
2. 按微信小游戏官方注册流程创建账号，确认账号与 AppID 属于小游戏，并在后台核对游戏类目及所需主体资料。
3. 在 Windows/macOS 微信开发者工具中导入解压目录，使用自己的小游戏 AppID；配置已是 `compileType: game`。
4. 点击编译，完成本文验收清单、扫码真机与包体检查。
5. 上传开发版本，到账号后台设置体验版、填写真实发布资料并提交审核；审核通过后由有权限的账号发布。

[微信官方小游戏示例](https://github.com/wechat-miniprogram/minigame-demo)与[官方模板工具](https://github.com/wechat-miniprogram/miniprogram-cli)区分普通小程序和小游戏运行时。本次已迁移入口与渲染，没有只给原 Page/WXML 工程换 AppID。仓库根目录仍保留小程序参考版；正式小游戏应导入专用导出目录。

## 从源码生成

首次接入可先看 [中文接入指南](../微信小游戏接入指南.md)。

Node.js 18+，无第三方 npm 依赖；普通小游戏导出和正式候选打包均需系统 `zip/unzip` 命令：

```sh
npm run verify
npm run package:minigame
```

显式收录小游戏入口、Canvas运行时/控制器/绘图器、共享规则、版本与卡牌资料、7张PNG、小游戏与项目配置。JS语法、模块与资源路径、工程类型、体积预算和哈希会进行检查。导出 ZIP 可重复生成，生成失败保留旧有效交付。

工程不需要后端、登录、云开发或构建 npm。微信工具自行生成真实上传包，源码 ZIP 不等于平台上传包。

## 本机正式账号配置

```sh
cp release.local.example.json release.local.json
```

用编辑器填入实际小游戏 AppID，`accountType` 保持 `game`。本机文件被 Git、源码归档和运行时打包排除。可选环境变量 `WECHAT_APPID`、`WECHAT_ACCOUNT_TYPE` 优先于本机文件。

```sh
npm run release:check
npm run package:release
```

默认检查要求实际 AppID 格式有效且明确声明小游戏类型。普通小程序账号、空值和版本/资源问题会阻止候选生成。通过后在 `.artifacts/release/` 生成 `ember-duel-1.1.0-rc` 目录、ZIP和哈希清单；AppID仅写副本，不改源码。候选工具使用系统 `zip/unzip`，已有导入包可直接使用微信工具图形界面操作。

检查报告分别记录源码、身份和平台状态。格式有效不证明账号归属或权限；`release_ready` 保持 false，直到在平台实际完成相应步骤，不把自动化测试当作平台验收。

## 编译与真机验收

| 场景 | 应确认的行为 |
| --- | --- |
| 开始与帮助 | 主图、开始、规则、关于都能打开，返回可继续操作 |
| 模式与祝福 | 三种模式切换明确，试炼三种祝福生效，经典对决使用原数值 |
| 护盾 | 铁壁模式先扣盾再扣生命，护盾值、战报与生命伤害统计一致 |
| 选卡与攻击 | 己方先手，选中与目标区明确，触摸一次只行动一次 |
| 龙焰 | 对存活敌人各12点，每局一次，随后交给对手 |
| 精准射击 | 可进入/取消瞄准，选中敌人造成50点，每局一次 |
| AI | 普攻或按有效伤害收益使用震地，无重复回合 |
| 滚动 | 小屏上下拖动查看详情与按钮，拖动结束不误触 |
| 战报 | 可查看完整记录，离开战报回战场只恢复一个待执行AI |
| 胜负与重开 | 玩家和AI获胜都能结算，伤害/回合正确，再战清旧状态 |
| 星级目标 | 获胜、战场限时内获胜、至少一人保有半数生命各一星；经典9/疾风8/铁壁12次行动，失败零星，再战重算 |
| 前后台与尺寸 | 切后台暂停、回来恢复，变化尺寸后画布清晰且触点正确 |
| 退出与重进 | 新局不会执行旧局回调，不继承上一局技能次数 |

至少在 iOS 和 Android 各完成一场胜利和失败，检查小屏、胶囊按钮、安全区、字体、触控及控制台。当前云环境可做 JS/状态/Canvas 浏览器模拟和文件检查，没有真正微信工具、扫码会话或设备，尚未取得这些平台验收结果。

## 保存发布基线

通过验证并提交源码后运行 `npm run archive:source`，得到完整源码 ZIP、Git bundle与提交/哈希清单；不要只保留精简小游戏包。该版本在独立 Git 开发分支中维护，之后的玩法从同一基线继续。云环境草稿保存不等于发布文件快照；可下载源码归档或使用远端 Git 分支恢复。
