# 隐私与素材事实表

用于当前 1.1.0 工程与账号后台填写核对，不代表微信平台已经批准。

| 项目 | 当前源码事实 |
| --- | --- |
| 账号与登录 | 不调用登录、手机号或用户资料接口 |
| 网络与后端 | 无业务网络请求、服务器或云开发依赖 |
| 个人信息 | 业务代码不收集、上传个人信息 |
| 第三方服务 | 无第三方统计、广告、支付或社交 SDK |
| 设备权限 | 不请求相册、定位、摄像头、麦克风等权限 |
| 对局数据 | 对局、祝福选择与星级仅保留在运行内存，不写入本地存档或上传；关闭后不保留 |
| 美术 | 本项目原创几何插画，运行时使用本地 PNG，设计源为 SVG |
| 账号主体信息 | 尚未提供，不虚构运营者名称、资质或联系方式 |

产品内「关于游戏与隐私」说明与上表一致。微信平台自身的账号与系统处理以其规则为准。未来如增加联网、登录、统计、广告、存档或权限，应同步修改实际实现与隐私说明，再重新核验平台配置。

最终提交时，请根据实际小游戏账号后台的要求填写主体、客服、简介、图标、类目和隐私资料；不能仅凭代码结构推断所有资质齐备。
